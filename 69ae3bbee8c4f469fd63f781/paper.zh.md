# 2.2 基础模型与算法

# 2.2.1 生成对抗网络 (GAN)

GAN是一种无监督机器学习模型，由两个神经网络在零和博弈框架中相互竞争实现[48]。GAN由生成器和判别器组成，其中生成器的角色是生成与真实数据（如图像）无法区分的数据，而判别器的角色是区分生成器产生的假数据和真实数据[49],[50]。GAN的优化目标涉及生成器$G$和判别器$D$之间的最小最大博弈。整体目标优化函数被表述为：

$$
\operatorname* { m a x } _ { D } { \underset { G } { \operatorname* { m i n } } } \mathbf { V } ( G , D ) ,
$$

价值函数 ${ \bf V } ( D , G )$ 定义为：

$$
\mathbb { E } _ { { x } \sim { p } _ { \mathrm { d a t a } } ( { x } ) } [ \log D ( { x } ) ] + \mathbb { E } _ { { z } \sim { p } _ { z } ( { z } ) } [ \log ( 1 - D ( G ( { z } ) ) ) ] .
$$

在这个框架中，生成器 $G$ 的目标是最小化判别器 $D$ 作出正确决策的概率。相反，判别器则致力于最大化其正确识别生成器输出的概率。真实数据 $x$ 是从数据分布 $p _ { \mathrm { d a t a } } ( x )$ 中采样的，而输入生成器的 $z$ 是从先验分布 $p _ { z } ( z )$ 中采样的，通常为均匀分布或高斯分布。期望算子 $\mathbb { E } ( \cdot )$ 表示相应概率分布下的期望值。这个对抗过程涉及交替优化判别器，以区分真实数据和虚假数据，以及优化生成器，以生成判别器会分类为真实的数据。这个训练过程持续进行，直到生成器产生的数据与真实数据如此接近，以至于判别器无法再区分两者。

# 2.2.2 变分自编码器 (VAE)

变分自编码器（VAE）代表了一类深度生成模型，其设计根植于贝叶斯推断的原则，促进了对数据潜在表示学习的结构化方法。VAE 由两个主要组件组成：编码器和解码器。编码器通常通过神经网络实现，功能是将输入数据映射到潜在空间中的概率分布。相反，解码器同样作为神经网络实现，目的是从这个潜在表示中重建输入数据，从而使模型能够捕捉基础数据分布。考虑一个数据集 $\mathcal{D} = \{ { x ^ { ( 1 ) } , x ^ { ( 2 ) } , . . . , x ^ { ( N ) } } \}$，它由从分布 $p(x)$ 中抽取的 $N$ 个独立同分布（i.i.d.）样本组成。VAE 的目标是用参数分布模型 $p_{\theta}(x)$ 近似这一分布，其中 $\theta$ 表示模型的参数。这个近似通过引入潜在变量 $\mathbf{z}$ 实现，导致联合分布可以表示为：通过优化证据下界（ELBO），VAE 学会在重建精度和潜在表示的复杂性之间取得平衡，使其能够生成与观察到的数据一致的新样本。

# 2.2.3 扩散模型

扩散模型是复杂的生成模型，通过逆转扩散过程来训练生成数据，如Ho等人在其2020年关于去噪的工作中所描述。这些模型逐步向数据引入噪声，最终通过一系列指定步骤将其转换为高斯分布。此转换由一个包含潜变量的马尔可夫链表示，$\{ \stackrel { \cdot } { x _ { t } } \} _ { t = 0 } ^ { T }$，其中$x _ { 0 }$表示初始数据，而$x _ { T }$代表完全被噪声污染的数据。正向扩散通过一系列转移概率$q \big ( x _ { t } | x _ { t - 1 } \big )$来表征，该概率系统性地将噪声引入数据中：

$$
q ( x _ { t } | x _ { t - 1 } ) = \mathcal { N } ( x _ { t } ; \sqrt { 1 - \beta _ { t } } x _ { t - 1 } , \beta _ { t } \mathbf { I } ) ,
$$

$$
\begin{array} { r } { p _ { \boldsymbol { \theta } } ( x , \mathbf { z } ) = p _ { \boldsymbol { \theta } } ( x | \mathbf { z } ) p ( \mathbf { z } ) . } \end{array}
$$

在这里，$p ( \mathbf { z } )$ 是潜在变量的先验，通常选择为标准高斯分布。术语 $p _ { \boldsymbol { \theta } } ( \boldsymbol { x } | \mathbf { z } )$ 代表似然性，由解码器网络建模。编码器通过使用变分分布 $q _ { \omega } ( \mathbf { z } | x )$ 来近似后验 $p _ { \boldsymbol { \theta } } ( \mathbf { z } | \boldsymbol { x } )$ ，从而促进这一过程，其中 $\omega$ 表示编码器的参数。训练变分自编码器（VAE）从根本上是关于最大化观测数据的边际似然上的证据下界（ELBO），其公式为：

$$
\begin{array} { r } { \mathcal { L } ( \boldsymbol { \theta } , \omega ; \boldsymbol { x } ) = \mathbb { E } _ { q _ { \omega } ( \mathbf { z } | \boldsymbol { x } ) } [ \log p _ { \boldsymbol { \theta } } ( \boldsymbol { x } | \mathbf { z } ) ] - \mathrm { K L } [ q _ { \omega } ( \mathbf { z } | \boldsymbol { x } ) \| p ( \mathbf { z } ) ] , } \end{array}
$$

其中第一个项是重建损失，旨在鼓励解码样本与原始输入匹配，第二个项是近似后验与先验之间的库尔被克尔发散，用作正则化。由此，$\{ \beta _ { t } \} _ { t = 1 } ^ { T }$ 是预定义的小方差，逐渐增强噪声。去噪扩散概率模型（DDPM）[52]，在[52]中被强调，是扩散模型的一个重要子集。它们将生成过程解释为一个反向扩散，顺序地净化数据，将随机噪声转化为预期分布中的样本。DDPM 确定了去噪函数 $\epsilon _ { \theta } ( x _ { t } , t )$ 来估计每一步添加的噪声，反向机制由以下定义：

$$
\begin{array} { r } { p _ { \theta } ( x _ { t - 1 } | x _ { t } ) = \mathcal { N } ( x _ { t - 1 } ; \mu _ { \theta } ( x _ { t } , t ) , \Sigma _ { \theta } ( x _ { t } , t ) ) , } \end{array}
$$

其中 $\mu _ { \theta } ( x _ { t } , t )$ 和 $\Sigma _ { \theta } ( x _ { t } , t )$ 是由神经网络确定的函数，用于逐步净化数据。训练的主要目标在于增强神经网络，以减少噪声数据与其去噪版本之间的差距，通常通过优化变分下界来实现。DDPM 的关键见解在于反转扩散过程，需估计逆条件概率。通过训练神经网络在每个阶段消除噪声，该模型能够通过反复应用所学习的去噪函数，从纯噪声中生成高质量样本。

# 2.2.4 自回归模型

自回归（AR）模型是一类用于理解和预测时间序列中未来值的统计模型。AR模型的基本假设为，当前观察值是前面观察值的线性组合加上一些噪声项。阶数为 $O _ { \iota }$ 的AR模型，记作 $\operatorname { A R } ( o )$，一般形式可以表示为：

$$
v _ { t } = \sum _ { i = 1 } ^ { o } \theta _ { i } v _ { t - i } + \epsilon _ { t } ,
$$

其中，$v _ { t }$ 是时间序列的当前值。$\theta _ { 1 } , \theta _ { 2 } , \ldots , \theta _ { o }$ 是模型的参数。$v _ { t - 1 } , v _ { t - 2 } , \ldots , v _ { t - o }$ 是时间序列的前 $o$ 个值。$\epsilon _ { t }$ 是白噪声，它是一系列相互不相关的随机变量，均值为零且具有恒定的有限方差。在神经网络的背景下，自回归模型被扩展用于建模数据中的复杂模式。它们在各种架构中是基础，特别是在序列建模和生成建模任务中。通过捕捉序列中元素之间的依赖关系，自回归模型可以生成或预测序列中的后续元素，使其在语言建模、时间序列预测和生成图像建模等应用中至关重要。

# 2.2.5 变换器

Transformer模型基于自注意力机制、多头注意力和位置前馈网络的原理进行运作。自注意力机制使模型能够优先考虑输入序列的不同部分。它使用以下公式计算注意力评分：

$$
{ \mathrm { A t t e n t i o n } } ( Q , K , V ) = { \mathrm { s o f t m a x } } \left( { \frac { Q K ^ { T } } { \sqrt { d _ { k } } } } \right) V .
$$

在这里，$Q$、$K$ 和 $V$ 分别对应于查询、键和值矩阵，这些矩阵是从输入嵌入中派生的，$d_{k}$ 是键的维度。多头自注意力机制通过对查询、键和值应用不同的学习到的投影 $h$ 次，从而增强模型关注不同位置的能力，并同时执行注意力函数。结果会被拼接并进行线性变换，如下所示：$\mathbf{Mult i H e a d}(Q, K, V) = \mathbf{C o n c a t}(\mathrm{h e a d}_{1}, \ldots, \mathrm{h e a d}_{h}) \mathcal{W}^{O}$，其中 $\mathcal{W}_{i}^{Q}$、$\mathcal{W}_{i}^{K}$、$\mathcal{W}_{i}^{V}$ 和 $\mathcal{W}^{O}$ 是学习到的参数矩阵。

$$
\mathbf { h e a d } _ { i } = \mathbf { A t t e n t i o n } ( Q { \mathcal { W } } _ { i } ^ { Q } , K { \mathcal { W } } _ { i } ^ { K } , V { \mathcal { W } } _ { i } ^ { V } ) .
$$

位置逐层前馈网络被包含在每个Transformer层中，对每个位置施加两个线性变换，中间夹着ReLU激活，且对所有位置相同。

$$
\mathrm { F F N } ( x ) = \operatorname* { m a x } ( 0 , x \mathcal { W } _ { 1 } + b _ { 1 } ) \mathcal { W } _ { 2 } + b _ { 2 } .
$$

线性变换的权重和偏置分别用 $\mathcal { W } _ { 1 } , b _ { 1 } , \mathcal { W } _ { 2 } ,$ 和 $b _ { 2 }$ 表示。使用了层归一化和残差连接，Transformer 在每个子层周围添加了残差连接，随后进行层归一化。输出定义为：

$$
\operatorname { L a y e r N o r m } ( x + \operatorname { S u b l a y e r } ( x ) ) ,
$$

其中子层 $ ( x ) $ 是子层自身实现的函数。位置编码被纳入输入嵌入中，以提供位置信息，因为模型缺乏递归或卷积。这些编码与嵌入相加，并定义为：

$$
P E _ { ( p o s , 2 i ) } = \sin ( p o s / 1 0 0 0 0 ^ { 2 i / d _ { \mathrm { m o d e l } } } ) ,
$$

$$
P E _ { ( p o s , 2 i + 1 ) } = \cos ( p o s / 1 0 0 0 0 ^ { 2 i / d _ { \mathrm { m o d e l } } } ) .
$$

这里，pos 表示位置，而 $i$ 是维度。

# 3.1 进化生成器

尖端技术报告Sora [5]表明，尽管Sora生成的视频相较于现有作品具有显著的进步，但文本到视频（T2V）生成器的算法设计则呈现出谨慎的渐进性发展。Sora主要通过复杂的剪接和精细的优化技术来提升这一领域。此观察强调了对现有T2V算法进行全面评审的重要性。通过考察支撑当代T2V模型的基础算法，我们将其分为三个主要框架：基于GAN/VAE、基于扩散和基于自回归的方法。

# 3.1.1 基于GAN/VAE的

在文本到视频领域的初期探索阶段，研究人员主要集中于基于神经网络（NN）设计生成模型，例如变分自编码器（VAE）和生成对抗网络（GAN）。这些开创性的努力为直接从文本描述理解和开发复杂视频内容奠定了基础。在自动从文本描述生成视频的前沿工作中，研究者提出了一种创新方法，将 VAE 与递归注意力机制相结合。这种方法生成随着时间演变的帧序列，受文本输入的引导，独特地集中于每一帧，同时学习整个视频的潜在分布。尽管其具有创新性，VAE 框架面临一个显著的挑战，即“后验崩塌”。为此，引入了 VQ-VAE 模型，这是一种结合了离散表示优势与连续模型效能的创新模型。利用向量量化，VQ-VAE 在生成高质量的图像、视频和语音方面表现优异。类似地，GODIWA 设计基于预训练于 HowTo100M 数据集的 VQ-VAE 架构，展示了其在下游视频生成任务上的微调能力以及显著的零样本能力。

与直接从文本输入生成视频不同，[60] 的作者提出了 TGANs-C，这是一种从文本标题创建视频的方法。这种方法集成了一种新颖的机制，包括 3D 卷积和多组件损失函数，确保生成的视频在时间上保持一致并与标题在语义上相符。在这些创新的基础上，[58] 提出了一个先进的混合模型，结合了变分自编码器（VAE）和生成对抗网络（GAN），有效捕捉文本描述中的静态属性（例如，背景设置和物体布局）和动态元素（例如，物体或角色的移动）。该模型将视频生成过程从简单的文本输入提升为基于文本叙述的更复杂、更具细微差别的视频内容创作。在一个互补的进展中，[59] 创新性地将 GAN 与长短期记忆（LSTM）[62] 网络相结合，显著提高了文本生成视频的视觉质量和语义一致性，确保生成内容与其文本描述之间的更紧密对齐。

# 3.1.2 基于扩散的

在Ho等人开创性的论文中[52]，扩散模型的引入标志着文本到图像（T2I）生成领域的一个重要里程碑，催生了DALL·E [2]、Midjourney [3] 和Stable Diffusion [63]等前沿模型。鉴于视频本质上由考虑空间和时间信息的图像序列组成，研究人员已开始探讨基于扩散架构的模型生成高保真视频的潜力，这些视频源自文本描述。

视频扩散模型（VDM）是一项在文本到视频生成方面的开创性进展，显著增强了标准图像扩散方法以适应视频数据。VDM 解决了生成高保真视频时时间一致性这一关键挑战。通过创新的 3D U-Net 架构，该模型专为视频应用而设计，将传统的 2D 卷积增强为 3D，并整合了时间注意机制，以确保生成时间一致的视频序列。该设计保持了空间注意力，同时结合了时间动态，能够生成连贯的视频序列。同样，MagicVideo 及其后续版本 MagicVideo-V2 是文本到视频生成领域的重要创新，利用潜在扩散模型应对数据稀缺、复杂的时间动态和高计算成本等挑战。MagicVideo 引入了一种基于 3D U-Net 的架构，采用视频分布适配器和有向时间注意等增强特性，实现高效、高质量的视频生成，保持时间一致性和真实感。它在潜在空间中操作，专注于关键帧生成和高效视频合成。MagicVideo-V2 在此基础上构建，整合了一个多阶段管道，包含文本到图像、图像到视频、视频到视频以及视频帧插值等模块。

潜在空间的利用是多种模型中的一个共同主题。LVDM [14] 提出了一个分层潜在视频扩散模型，将视频压缩到低维潜在空间中，从而实现高效的长视频生成并降低计算需求。传统框架仅限于生成短视频，其长度由训练阶段提供的输入帧数预先确定。为克服这一限制，LVDM 引入了一种条件潜在扩散方法，能够根据之前的潜在编码以自回归方式生成未来的潜在编码。Show-1 [28]、PixelDance [67] 和 SVD [63] 利用基于像素和基于潜在的技术生成高分辨率视频。Show-1 从基于像素的视频扩散模型 (VDM) 开始，生成准确的低分辨率关键帧，然后使用基于潜在的 VDM 进行高效的高分辨率视频增强，充分利用两种方法的优势，确保高质量且计算高效的视频输出。PixelDance 建立在潜在扩散框架上，经过训练以去噪扰动输入，旨在最小化计算需求。其基本结构是一个 2D UNet 扩散模型，通过加入时间层（包括沿时间维度的 1D 卷积和注意力机制）增强为 3D 变体，适应视频内容，同时保持对图像输入的有效性。该模型能够与图像和视频进行联合训练，通过有效整合空间和时间分辨率，确保高保真度的输出。SVD 将时间卷积和注意力层融入预训练的扩散架构中，使其能够高效捕捉动态变化。Tune-A-Video [68] 通过引入时间自注意力捕捉帧间的一致性，扩展了这些概念，并优化了计算资源。具体来说，Tune-A-Video 旨在解决计算开销问题，并将 2D 潜在扩散模型 (LDM) 扩展到时空域以促进 T2V 生成。[68] 的研究人员创新性地在网络中的每个变压器块中添加了一个时间自注意力层，使得模型能够捕捉视频帧间的时间一致性。这一设计辅以稀疏时空注意力机制和选择性调优策略，仅更新注意力块中的投影矩阵，以优化计算效率，并保留 T2I 模型中预先学习的特征，同时确保生成视频的时间连贯性。

在视频增强领域，VideoLCM [69] 模型被设计为一种潜在一致性模型，采用一致性蒸馏策略进行优化，旨在减少计算负担并加速训练。该模型利用大规模预训练的视频扩散模型来提高训练效率。模型应用 DDIM [70] 求解器来估计视频输出，并结合无分类器引导以合成高质量内容，使其能够以最少的采样步骤实现快速且高效的视频合成。VideoCrafter2 [71] 模型被独特地设计用于增强视频扩散模型中的时空一致性，采用创新的数据级解耦策略，精确地将运动特征与外观特征分离。这一战略设计使得高质量图像的针对性微调过程得以实现，旨在显著提高生成内容的视觉保真度，而不妥协运动动态的精确性。这一方法在 VideoCrafter1 [72] 的基础上进行了重要的改进，后者被构建为潜在视频扩散模型（LVDM），融合了视频变分自编码器（VAE）和视频潜在扩散过程。视频 VAE 将视频数据压缩为较低维度的潜在表示，然后由扩散模型处理以生成视频。

像 Make-A-Video 和 Imagen Video 这样的模型将文本到图像的技术扩展到视频领域。Make-A-Video 模型利用了 T2I 技术的进步，并将其扩展到视频领域，而无需配对的文本-视频数据。它围绕三个核心组件设计：一个 T2I 模型、时空卷积和注意力层，以及一个帧插值网络。最初，它利用一个在文本-图像对上训练的 T2I 模型，然后通过引入纳入时间动态的新型时空层进行扩展，最后，利用帧插值网络提高生成视频的帧率和流畅度。Imagen Video 采用了一种复杂的级联架构，设计用于 T2V 合成，专门针对视频扩散模型。这种设计将基本视频扩散模型与后续的空间和时间超分辨率模型巧妙结合，所有这一切都基于文本提示，以逐步提高生成视频的质量和分辨率。该模型的创新结构使其不仅能够生成高保真度和高分辨率的视频，还展现出强大的时间连贯性和与描述性文本的对齐。MotionDiffuse: 驱动文本的人类动作生成，特别是在生成动作中对多样性和细粒度控制的需求。采用了专门为将文本描述与动作生成相结合而设计的跨模态线性变换器的扩散模型。它在生成的动作上实现了细粒度的控制，允许对身体部位和时间变化序列进行独立控制，确保输出的多样性和现实性。Text2Video-Zero 建立在稳定扩散的 T2I 模型之上，专为零-shot T2V 合成而设计。核心增强包括为潜在编码引入运动动态以保持时间一致性，并采用跨帧注意力机制，确保对象外观和身份在帧间的保留。这些修改使得从文本描述生成高质量、时间一致的视频序列成为可能，而无需额外的训练或微调，利用了预训练 T2I 模型的现有能力。NUWA-XL 引入了一种新颖的“扩散中的扩散”架构，专门用于生成超长视频。它所解决的主要挑战是现有方法在生成长视频时的低效和质量差距，NUWA-XL 的架构创新性地采用了“粗到精”的策略。它从一个生成视频粗略结构的全局扩散模型开始，随后局部扩散模型进一步细化这些关键帧，填充它们之间的详细内容，使系统能够高效地生成既具全球连贯性又具有细粒度细节的视频。

与微调预训练模型的方法不同，Sora 旨在从零开始训练扩散模型，提出了一个明显更具挑战性的任务。受到变换器架构可扩展性的启发，OpenAI 将 DiT 框架整合到其基础模型架构中，将扩散模型从传统的 U-Net 转变为基于变换器的结构，利用变换器的可扩展能力高效地训练大量数据并应对复杂的视频生成任务。类似地，GenTron 在 DiT-XL/2 结构的基础上，旨在通过整合变换器和扩散模型提高训练效率，将潜在维度转换为通过变换器块处理的不重叠词元。该模型的创新在于其文本条件化，采用自适应层归一化和交叉注意机制来整合文本嵌入并增强与图像特征的互动。GenTron 的一个显著特点是其可扩展性；GenTron-G/2 变种将模型扩展到超过 30 亿个参数，关注变换器块的深度、宽度和 MLP 宽度。同时，W.A.L.T 基于一个包含自编码器和新型变换器架构的两阶段过程。最初，自编码器将图像和视频压缩到较低维度的潜在空间，从而实现对组合数据集的高效训练。变换器采用窗口限制自注意层，在空间和时序注意之间交替进行，这显著降低了计算需求，同时支持图像和视频的联合处理。这一结构使得从文本描述生成高分辨率、时间一致的视频成为可能，展示了 T2V 合成中的一种创新方法。Latte 进一步扩展了这些创新，采用一系列变换器块处理通过预训练变分自编码器获得的视频数据的潜在空间表示。这种方法能够有效建模视频数据固有的复杂分布，以创新的方式处理空间和时间维度。

# 3.1.3 自回归模型

最近，在T2V生成领域的进展中，自回归基础的变换器技术得到了显著关注，因其在处理序列数据和可扩展性方面具备优秀的效率。这些特性对于建模视频生成任务的复杂时间动态和高维数据特征至关重要。变换器特别有利于与现有语言模型的无缝集成，从而促进连贯且上下文丰富的多模态输出的生成。在这一领域，一个显著的发展是NUWA，它将3D变换器编码器-解码器框架与专门的3D邻近注意力机制结合起来，使得通过处理一维、二维和三维数据有效且高质量地合成图像和视频，展现出显著的零样本能力。在此基础上，NUWA-Infinity引入了一种创新的自回归过自回归框架，能够生成可变大小的高分辨率视觉内容。该框架结合了全局碎片级和局部词元级模型，增强了邻近上下文池和任意方向控制器，以确保无缝、灵活且高效的视觉内容生成。进一步扩展这些能力，Phenaki以其独特的C-ViViT编码器-解码器结构拓展了这一范式，专注于从文本输入生成可变长度的视频。该模型有效地将视频数据压缩为紧凑的词元表示，促进生成连贯、细致且时间一致的视频。同样，VideoGPT是一个创新性地结合VQ-VAE和变换器架构以应对视频生成挑战的模型。它通过3D卷积和轴向注意力学习视频的下采样离散潜在表示，从而创建一个紧凑且高效的视频内容表示。这些学习到的潜在表示随后通过变换器进行自回归建模，使模型能够捕捉视频序列的复杂时间和空间动态。

大型世界模型（LWM）[80] 代表了又一次进步，旨在作为一种自回归变换器处理长上下文序列，结合视频和语言数据实现多模态理解与生成。其设计的关键在于环形注意力机制，该机制有效应对处理多达100万个词元的计算挑战，既降低内存成本，又最大化上下文感知。该模型采用 VQGAN 进行视频帧的词元化，将这些词元与文本融合，实现全面的序列处理。另一方面，Genie [81] 模型被设计为一种生成互动环境工具，所有组件均采用时空（ST）变换器，利用新颖的视频词元化器和因果动作模型提取潜在动作，然后将其传递给动态模型。该动态模型自回归地预测下一帧，采用 ST 变换器架构，在模型容量和计算效率之间取得平衡。该模型的设计充分发挥变换器的优势，特别是在处理视频数据的序列和时空方面，以生成可控和互动的视频环境。TATS [12] 专门设计用于生成长时间的视频，解决了在较长序列中保持高质量和一致性的挑战。该模型架构创新性地结合了时间无关的 VQGAN，确保视频帧的质量而不受时间依赖，同时采用时间敏感的变换器，以捕捉长程时间依赖。此双重方法使得生成高质量、一致的长视频成为可能，为视频合成领域设定了新的标准。CogVideo [82] 整合了多帧率的分层训练方法，基于预训练的 T2I 模型 CogView2 [83] 进行适应性改进，以增强 T2V 合成。该设计继承了 CogView2 的文本-图像对齐知识，利用这些知识从文本生成关键帧，然后插值中间帧以创建一致的视频。该模型的双通道注意力机制和递归插值过程能够实现详细且语义一致的视频生成。

# 3.2 卓越追踪

Sora在展示的演示中展现了其出色的视频生成能力，具有长时段、高分辨率和流畅性。基于这些优点，我们将当前的研究工作分为三类：扩展时长、卓越分辨率和无缝质量。

# 3.2.1 延长持续时间

与短视频生成或图像生成任务相比，长期视频生成更加具有挑战性，因为后者需要具备建模长时间范围时间依赖性的能力，并且需要在更多帧中保持时间一致性 [5]。

具体而言，随着生成视频时长的延长，一个障碍是预测误差会积累。为了解决这一挑战，引入了回溯机制（LTVR）【11】，旨在使回溯帧与观测帧保持一致，从而减轻积累的预测误差。TATS【12】通过结合时间无关的VQGAN进行高质量帧生成和时间敏感的Transformer捕捉长范围时间依赖关系，实现了长视频生成的目标。Phenaki【13】被提出用于从开放域文本描述生成视频。通过引入设计的因果注意力，它能够处理变长视频，并通过新的提示扩展视频以生成更长的序列。LVDM【14】提出了一个分层框架以生成更长的视频，使其能够生成超过千帧的视频。Make-A-Video【73】通过利用T2I模型进行视觉学习和无监督视频数据进行运动理解，能够生成高保真度和多样性的长视频，而无需成对的文本-视频数据。StyleInV【15】能够通过稀疏训练方法和高效的运动生成器设计生成长视频。通过用初始帧约束生成空间和采用时间风格编码，该方法实现了高单帧分辨率和质量，以及在长时间范围内的时间一致性。最近，通过增强片段中的时空一致性，Vlogger【16】成功地从开放世界描述中生成超过5分钟的博客视频，而未失去有关剧本和角色的视频一致性。MoonShot【17】利用多模态视频块，将时空层与解耦的交叉注意力进行集成，以实现多模态条件，并直接使用经过预训练的图像控制网络（Image ControlNet）【18】进行精确的几何控制，从而高效地处理多样化生成任务，生成具有高视觉质量和时间一致性的长视频。

此外，受到隐式神经表示（INR）[19] 在建模复杂信号方面成功的启发，多个研究工作将INR引入视频生成领域。例如，DIGAN [20] 利用隐式神经表示（INR）的紧凑性和连续性，合成高分辨率的长视频，而不需要大量训练资源，从而实现对长视频的高效训练。同样，StyleGAN-V [21] 通过将视频视为连续信号，能够高效生成任意长度和任意帧率的视频。此外，还有多个研究从分解的角度出发，以解决视频生成过程中的长程一致性问题。在GenL-Video [22]中，长视频首先被感知为短片段。开发了双向跨帧注意机制，以促使不同视频片段之间的相互影响，从而找到兼容的去噪路径来生成长视频。SEINE [23] 采取了类似的方法，将长视频视为各种场景和不同长度的镜头视频的组合。通过合成各种场景的长期视频，SceneScape [24] 被提出以根据文本描述生成长期视频，解决视频生成中的三维一致性挑战。NUWAXL [25] 提供了一种基于粗到细策略的新颖解决方案，开发了“扩散中的扩散”架构，实现了极长视频的高效且连贯的生成。MCVD [26] 通过自回归地生成帧块，生成任意长度的视频，从而能够为多种类型的视频（包括长时间内容）制作高质量的帧。

# 3.2.2 优越分辨率

与低质量视频相比，高分辨率视频无疑在自主技术的模拟引擎等应用领域具有更广泛的潜力。另一方面，高分辨率视频生成也对计算资源提出了挑战。针对这一挑战，视频潜在扩散模型（LDM）[27]引入了现成的预训练图像LDM，以实现视频生成的同时避免过高的计算需求。通过训练时间对齐模型，视频LDM能够生成高达 $1 2 8 0 \times 2 0 4 8$ 的视频分辨率。

然而，潜在扩散模型（LDM）在生成精确的文本与视频对齐方面存在困难。在 Show-1 中，结合了基于像素和基于潜在变量的视频扩散模型（VDM）的优势，形成一种混合模型。Show-1 利用基于像素的 VDM 初始化低分辨率视频生成，然后使用基于潜在变量的 VDM 进行上采样，以获取高分辨率视频（最高可达 $5 7 2 \times 3 2 0$）。最近，STUNet 采用了一种空间超分辨率（SSR）模型来对基础模型的输出进行上采样。具体而言，为了避免时间边界伪影并确保时间段之间的平滑过渡，沿时间轴应用了多重扩散，使 SSR 网络能够在视频的短段上操作，通过平均重叠像素的预测来生成高分辨率视频。从另一个角度来看，视频生成被视为在 MoCoGAN-HD 中发现问题的轨迹，该框架利用当代图像生成器渲染高分辨率视频（最高达到 $1 0 2 4 \times 1 0 2 4$）。在文本驱动的人物视频生成任务中，作为视频生成的一个子领域，Text2Performer 通过将潜在空间分解为单独处理人物外观和动作并利用连续姿态嵌入进行动作建模，实现了生成高分辨率人物视频的目标（最高可达 $5 1 2 \times 2 5 6$）。这种方法确保了外观在帧之间保持一致，同时根据文本描述生成时间上连贯且灵活的人物动作。

# 3.2.3 无缝质量

在可视性方面，高帧率视频相比于不流畅的视频更具吸引力，因为它避免了常见的伪影，如时间抖动和运动模糊 [32]。

深度感知视频帧插值方法 (DAIN) [32] 被引入以利用深度信息来检测遮挡并在插值过程中优先考虑更近的物体。通过引入一个深度感知流投影层，该层通过优先对近物体进行采样来合成中间流，从而解决了视频帧中的遮挡和运动挑战。通过利用循环一致性损失、运动线性损失和边缘引导训练，CyclicGen [33] 在生成高质量插值帧方面表现优异，这是高帧率视频生成的关键。Softmax-Splatting [34] 中引入的 Softmax splatting 方法可以在任何所需的时间位置插值帧，有效促进高帧率视频的生成。目前，FLAVR [35] 通过设计利用三维时空卷积进行运动建模的架构，解决了生成高帧率视频的挑战。此外，为了减轻计算限制，FLAVR 直接从视频数据中学习运动特性，从而简化了训练和部署过程。

# 3.3 真实全景

T2V 生成中的一个关键挑战是实现逼真的视频输出。解决这一问题需要关注实现逼真所必需的元素整合。分析逼真的全景 T2V 生成，我们识别出以下关键组件需要考虑：1. 动态运动 2. 复杂场景 3. 多个物体 4. 合理布局。

# 3.3.1 动态运动

近年来，尽管在文本到图像（T2I）生成方面取得了显著进展，但许多研究人员已开始探索将T2I模型扩展至文本到视频（T2V）生成，如LAMP和AnimateDiff。运动是视频与图像之间的关键区别之一，也是这一新兴研究领域的重点。LAMP专注于从有限的数据集中学习运动模式。它采用一种以第一帧为条件的流程，通过利用预训练的T2I模型生成初始帧，使视频扩散模型能够集中学习后续帧的运动。这一过程通过时空运动学习层得到增强，能够捕捉时间和空间特征，从而简化视频中的运动生成。AnimateDiff将预训练的运动模块集成到个性化T2I模型中，能够生成流畅且内容对齐的动画。该模块采用了一种新策略进行优化，从视频数据中学习运动先验，关注动态而非像素细节。一个关键创新是MotionLoRA，这是一种微调技术，使该模块能够适应新的运动模式，增强其在不同摄像机移动中的多样性。

运动一致性和连贯性也是运动生成中的关键挑战。与传统模型生成关键帧后再填补空白、经常导致不一致的方式不同，Lumiere [29] 使用了一种时空 U-Net 架构，在一次传递中生成整个视频。该方法通过结合空间和时间的下采样和上采样，确保了全局时间一致性，显著提高了运动生成性能。Dysen-VDM [88] 集成了一个动态场景管理器（Dysen），其运作分为三个协调的步骤：从文本中提取关键动作，将其转换为动态场景图（DSG），并用上下文场景细节丰富 DSG。这种方法能够生成时间上连贯和上下文丰富的视频场景，与输入文本中描述的意图动作紧密对齐。ART• V [89] 关注一种创新方法，解决了建模复杂长程运动的挑战，通过顺序生成视频帧，每个帧都依赖于其前面的帧。这一策略确保了连续和简单的运动的产生，保持相邻帧之间的连贯性。DynamiCrafter [90] 则专注于一种双流图像注入机制，整合了文本对齐的上下文表示和视觉细节指导。这种方法确保动画内容在视觉上与输入图像保持一致，同时与文本描述在动态上保持一致。

几项研究集中于改善文本到视频（T2V）中的运动生成。PixelDance专注于通过整合视频首帧和末帧的图像指令以及文本指令，丰富视频动态。这种方法使得模型能够捕捉复杂场景转换和动作，增强生成视频的运动丰富性和时间一致性。MoVideo使用从关键帧提取的深度和光流信息指导视频生成过程。最初，从文本生成一幅图像，然后从该图像中提取深度和光流。MicroCinema采用双阶段过程，首先从文本生成关键图像，然后利用图像和文本指导视频创建，重点捕捉运动动态。ConditionVideo将视频运动分为背景和前景组件，提高了生成视频内容的清晰度和控制能力。DreamVideo将视频生成任务解耦为主体学习和运动学习。运动学习部分专门针对有效适应新的运动模式，对模型进行调整。他们引入了一种运动适配器，当与外观指导结合时，使模型能够专注于学习运动，而不受主体外观的影响。TF-T2V使得在没有文本注释的情况下学习复杂运动动态，使用图像条件模型有效捕捉多样化的运动模式，并包含时间一致性损失，增强帧间的连续性。GPT4Motion使用GPT-4生成Blender脚本，这些脚本用于驱动Blender的物理引擎，模拟与给定文本描述相对应的真实物理场景。这些脚本与Blender的仿真能力的结合，确保生成的视频不仅在视觉上与文本提示一致，而且保持物理现实性。然而，尤其在人体动作生成方面仍面临挑战。Text2Performer不同于传统的离散VQ模型，通过生成连续的姿势嵌入，提高了生成视频的运动真实感和时间一致性。MotionDiffuse则侧重于一种概率策略，促进从文本描述中创建多样而栩栩如生的运动序列。将去噪扩散概率模型（DDPM）与跨模态变换器架构相结合，使系统能够生成与文本输入一致的复杂、持续的运动序列，确保生成动画的高保真度和精确可控性。

# 3.3.2 复杂场景

生成复杂场景的视频具有极高的挑战性，因为需要对细致的环境、动态交互和变化的光照条件进行复杂的理解和高保真度的复制。在研究的初期阶段，文献[40]中的作者提出了一种包含新颖时空卷积架构的生成对抗网络（GAN）。该架构有效捕捉了场景中前景和背景元素的动态。通过在大规模无标签视频数据集上训练模型，它学习从静态图像预测合理的未来帧，从而生成具有真实场景动态的视频。这种方法使模型能够通过理解和生成场景中不同组件的时间演变来处理复杂场景。随后，随着大语言模型（LLM）的发展，研究人员深入探讨了如何利用其能力来增强生成模型，以制作复杂场景。VideoDirectorGPT [41] 利用 LLM 进行视频内容规划，生成详细的场景描述和实体布局，并确保场景间的视觉一致性。通过采用新颖的 Layout2Vid 生成技术，确保场景间的空间和时间一致性，从而生成丰富的叙事驱动的视频内容。类似地，FlowZero [42] 通过一种新框架增强时空布局与文本提示之间的对齐，促进零样本 T2V 合成。FlowZero 将文本提示初步翻译成详细的动态场景语法（DSS），概述场景描述、物体布局和运动模式，然后通过自我优化过程迭代精炼这些布局，以符合文本提示，从而合成具有复杂运动和变化的时间连贯视频。VideoDrafter [43] 利用 LLM 将输入提示转换为全面脚本，识别常见实体并为每个实体生成参考图像。然后，VideoDrafter 通过考虑参考图像、描述性提示和摄像机运动来生成视频，整个过程通过扩散过程保证场景间的视觉一致性。SceneScape [24] 强调在 3D 场景合成中生成更复杂场景的视频。通过使用预训练的文本到图像和深度预测模型，确保生成的视频在测试时优化过程中保持 3D 一致性。它采用渐进策略，不断构建和更新场景的统一网格表示，从而保证几何合理性。

# 3.3.3 多目标对象

对于视频的每一帧，生成多个物体面临诸多挑战，例如属性混合、物体混合和物体消失。属性混合发生在物体无意间和错误地采纳其他物体的特征时。物体混合和消失涉及不同物体的融合，导致产生奇特的混合物和不准确的物体计数。为了解决这些问题，检测引导（DG）集成了潜在物体检测模型，以增强生成图像中不同物体的分离与清晰度。他们的方法操控交叉注意力图，精炼物体表示，展示了在无需人工干预的情况下生成独特物体的显著改善。视频合成的复杂性要求捕捉物体之间的动态时空关系。MOVGAN借鉴了布局到图像生成的进展，通过使用隐式神经表示和自推断布局运动技术进行创新。这一方法不仅能够生成描绘单个物体的影片，还能准确表示物体之间的交互和随时间的运动，增强合成视频内容的真实感和深度。在T2V生成领域，处理单个视频帧内多个对象的视觉特征至关重要，因其涉及属性绑定问题。VideoDreamer利用稳定扩散与潜在代码运动动态和时间交叉帧注意力，进一步通过Disen-Mix微调和可选的人类参与再微调策略进行定制。它成功生成高分辨率视频，同时保持时间一致性和主体身份而不产生伪影。UniVG通过增强基础模型的多条件交叉注意力来应对多物体生成挑战，以有效管理来自文本和图像输入的复杂场景。而对于自由度较低的任务，它引入偏置高斯噪声，以更有效地保留内容，支持图像动画和超分辨率等任务。这些创新使UniVG能够在各种生成任务中生成语义对齐的高质量视频，有效应对多物体场景的复杂性。

# 3.3.4 理性布局

在文本到视频（T2V）转换中，确保高质量视频输出依赖于根据文本指令生成合理布局的能力。Craft [44] 旨在从文本描述生成视频，通过学习视频-字幕数据来预测场景中实体的时间布局，从视频数据库中检索时空片段，并将其融合生成场景视频。它结合了布局构建器模型，理解实体之间的空间关系，从而生成合理的场景布局。Craft采用一种顺序方法，将文本嵌入和场景上下文相结合，准确预测角色和物体的位置和大小，促进视觉上连贯和上下文准确的视频创作。FlowZero [42] 利用大型语言模型（LLMs）生成布局，将文本提示转换为结构化语法，以指导生成时序一致的视频。这个过程包括逐帧场景描述、前景物体布局和背景运动模式。具体而言，对于前景布局，LLMs生成一系列特定于帧的布局，勾画出了每一帧中前景实体的空间排列。这些布局由定义提示参考对象位置和大小的边界框组成。这种结构化的方法确保前景物体遵循文本中提供的视觉和时空线索，从而增强视频的连贯性和保真度。然而，[45] 的作者指出，现有模型在处理复杂的时空提示时面临挑战，常常导致运动有限或错误，例如，无法准确表示物体从左向右移动。为了解决这些不足，他们提出了基于大型语言模型的动态视频扩散（LVD），这是一种新方法，通过首先利用大型语言模型生成动态场景布局（DSLs），然后使用这些DSLs来指导扩散模型进行视频生成，从而增强神经视频生成的能力。该方法克服了当前模型在生成具有复杂时空动态的视频方面的限制，在生成与期望属性和运动模式高度一致的视频方面取得了显著更好的性能。

# 3.4.1 数据集

我们综合回顾了 T2V 数据集，并主要根据收集的领域将其分类为六个类别：人脸、开放、电影、动作、指令和烹饪。表 1 汇总了 12 个维度的数据集，每个数据集的详细描述如下：CV-Text 是一个高质量的人脸文本-视频对数据集，包括 70,000 段野外人脸视频剪辑，分辨率至少为 $5 1 2 \times 5 1 2$。每个剪辑配有 20 个生成的描述，平均长度约为 67.2。MSR-VTT 提供了 10,000 个网络视频剪辑，共计 40 小时和 200,000 对剪辑-句子对。每个剪辑大约伴随 20 个自然句子用于描述。视频数量约为 7,200，平均每个剪辑和句子的时长分别为 15.0 秒和 9.3 个词。DideMo 由超过 10,000 个未经编辑的个人视频组成，涵盖多种视觉场景，并配有局部视频片段和指称表达对。YT-Tem-180M 从 600 万个公共 YouTube 视频收集，包含 1.8 亿个剪辑，并由 ASR 进行了注释。WebVid2M 包含 250 万个视频-文本对。每个视频和句子的平均长度分别为 18.0 秒和 12.0 个词。每个视频的原始描述来自与网页图像相关联的 Alt-text HTML 属性。HD-VILA-100M 是一个大规模的文本-视频数据集，从 YouTube 收集，包含 1 亿个高分辨率（720P）视频剪辑和来自 330 万个视频的句子对，视频总时长为 371.5K 小时，并有 15 个热门类别。InternVid 是一个大规模的视频中心多模态数据集，能够学习强大且可转移的视频-文本表征以实现多模态理解和生成。InterVid 包含超过 700 万个视频，持续近 760K 小时，生成的234M视频剪辑伴随总计 41 亿个词的详细描述。HD-VG-130M 包含来自开放领域的 1.3 亿个文本-视频对，分辨率为 $1 3 7 6 \times 7 6 8$。数据集中大多数描述约为 10 个词。Youku-mPLUG 是第一个发布的中文视频语言预训练数据集，收集自优酷。它包含从 4 亿个原始视频中筛选的 1000 万个中文视频-文本对，涵盖 45 个不同种类的广泛范围。每个视频的平均时长约为 54.2 秒。VAST-27M 包含总计 2700 万个视频剪辑，涵盖不同类别，每个剪辑配有 11 个标题（包括 5 个视觉、5 个音频和 1 个全模态标题）。视觉、音频和全模态标题的平均长度分别为 12.5、7.2 和 32.4。Panda-70M 是一个高质量的视频-文本数据集，最初从 HD-VILA-100M 中策划而来。它的总时长为 166.8K 小时，包含 7080 万个视频，配有高质量的文本标题。每个视频的时长为 8.5 秒，每个句子的平均长度为 13.2 个词。LSMDC 包含约 118K 个与来自 200 部电影的句子对齐的视频剪辑。视频总时长约为 158 小时，每个剪辑和句子的平均时长分别为 4.8 秒和 7.0 个词。MAD 源于电影，包含超过 384K 个句子，基础于超过 1.2K 小时的 650 个视频。每个句子的平均长度为 13.2 个词。UCF-101 是一个关于人类动作的数据集，从 YouTube 收集样本，包含 101 个动作类别，包括人类运动、乐器演奏和交互动作。它包含超过 13K 个剪辑和 27 小时的视频数据。UCF-101 的分辨率和帧率为 $3 2 0 \times 2 4 0$ 和每秒 25 帧（FPS）。

# 4.2 数据访问隐私

受大型语言模型（LLMs）进展的启发，Sora 使用互联网规模的数据集进行训练。然而，互联网公开数据的广泛范围仅占可用信息总量的一小部分；大部分是来自个人、公司和机构的私有数据。与公开数据集相比，私有数据集丰富多样且重复项更少。然而，它们也蕴含大量敏感个人信息，尤其是图像和视频格式，其内容往往比纯文本更具个性化。这是一个关键区别，因为后者主要用于训练LLMs。因此，当公共数据资源被充分利用，并且旨在进一步增强模型能力，特别是在泛化能力方面时，制定策略以非敏感隐私数据的方式严格保护隐私变得至关重要。联邦学习（FL），如文献[133]中所介绍，提供了一种有前景的解决方案，能够让成千上万的客户端利用自己的数据协作贡献全球模型，而无需在任何阶段转移原始数据。最近的研究验证了FL在微调LLMs[134]和增强扩散模型[135]方面的有效性。虽然FL能够有效解决分布式私有数据可访问性的问题，但仍面临重大挑战，包括网络瓶颈、异构数据、设备的间歇可用性等。

# 4.3 同步多镜头视频生成

多镜头视频生成是T2V领域中的一项重大挑战，该领域的视频生成仍然在很大程度上是未被充分探索的。直到Sora展示了其在这一领域的能力，这一状况才有所改变。凭借其先进的语言理解能力，Sora能够生成多镜头的视频，始终保持角色和视觉风格的一致性。这种能力标志着视频生成的一个重要进展，提供了一个连贯和持续的视觉叙事。尽管有了这些进展，Sora仍未掌握生成具有相同角色和一致视觉风格的同时多镜头视频的能力。这一能力对某些领域至关重要，例如机器人技术，在该领域中，从示范中学习是必不可少的；还有在自主车辆模拟中，一致的视觉表现对系统的有效性和可靠性起着关键作用。开发这一功能将标志着一项重大突破，拓宽T2V技术在关键现实应用中的适用性。

# 4.4 多智能体共创

由大型语言模型（LLM）驱动的智能体能够根据人类知识独立执行任务，而多智能体系统则将各个LLM智能体汇聚在一起，通过协作利用其集体能力和专业技能。在多智能体系统中，协作与协调至关重要，使得智能体集体能够承担超出任何单一实体能力的任务，并且智能体具有独特的能力并承担特定角色，共同努力实现共享目标。多智能体系统在反映和增强需要协作问题解决或审议的现实任务方面的有效性已在多个领域得到了验证，特别包括软件开发和谈判游戏等领域。尽管潜力巨大，多智能体系统在文本到视频（T2V）生成领域的应用仍然 largely 未被探索，原因在于面临独特的挑战。以电影制作为例：智能体承担不同的角色，如导演、编剧和演员。每个演员必须根据导演的指示生成其片段，随后将这些片段整合成一个连贯的视频。主要挑战在于确保每个演员智能体不仅在其输出的每一帧之间保持一致性，还与集体愿景对齐，以维持全球视频风格一致性、逻辑屏幕布局和统一性。这尤其困难，因为生成模型的输出可能在类似提示下有显著差异。

# 5 未来方向

# 5.1 机器人通过视觉辅助学习

传统的机器人编程方法在处理新任务时需要广泛的编码专业知识和大量的时间投入。这些方法要求用户详细定义任务执行所需的每一步或每一动作。尽管运动规划策略减少了明确指定每个微小动作的必要性，但仍然需要识别更高层次的动作，比如设定目标位置和途经点的顺序。为了解决这些挑战，最近的研究逐渐转向示范学习（LfD），这一范式使机器人通过观察和模仿专家的动作来学习新技能。然而，就如传统机器人研究在数据集收集方面面临挑战一样，获取LfD的示范视频也存在关键困难。尽管最近在简化数据收集的工具和方法方面有所进展，例如 UMI，但收集相关和全面的数据仍然是一个重大挑战。较新的生成模型研究，如大型语言模型（LLMs）和视觉语言模型（VLMs），在很大程度上缓解了这一障碍。这些创新使得机器人能够以零样本的方式使用预训练的LLM和LVM，例如VoxPoser，直接应用人类知识来完成新的机器人任务，而无需事先进行明确的训练。然而，在Sora公布之前，直接将T2V生成模型应用于机器人LfD是具有挑战性的。现有大多数模型在准确模拟复杂场景的物理特性方面面临困难，且往往缺乏对特定因果实例的理解。这个问题对于机器人学习的有效性至关重要；数据和现实条件之间的差异可能深刻影响机器人训练的质量，从而妨碍机器人的精确自主能力。

另一方面，三维重建技术，如神经辐射场（NeRF）和三维高斯点云（3DGS），在包括机器人研究在内的多个领域引起了广泛关注。DFFs通过捕捉场景图像，借助二维模型提取密集特征，并将其与NeRF整合，映射空间和视角细节，从而高效创建复杂的三维模型及交互。DFFs显示，与NeRF的三维重建信息整合使得机器人能够更好地理解和与环境互动，进而展示了三维重建信息如何帮助机器人更有效地完成任务。除此之外，Sora的一大显著特点是能够在单个样本中生成同一角色的多个镜头，确保视频中外观的一致性。通过将三维重建方法与Sora生成的多镜头视频相结合，可以利用这一能力，增强机器人通过演示的学习，从而准确捕捉场景。

# 5.2 无限 3D 动态场景重建与生成

3D场景重建近年来受到广泛关注。文献[147]中的工作作为从视频进行3D感知重建的开创性努力之一脱颖而出，通过整合GPS、惯性测量、相机位姿估计以及立体视觉、深度图融合和模型生成的先进算法，实现了显著的成果。然而，神经辐射场（NeRF）[144]的出现在该领域标志着一个实质性的简化。NeRF使用户能够从视频中直接重建对象，细节前所未有。尽管如此，重建高质量场景仍然需要大量的工作，特别是在获取众多视角或视频时，如文献[148]所强调的。当对象较大或环境使得捕获多视角视频变得困难时，这一挑战愈加明显。多项研究证明了从视频流中进行3D重建的有效性，其中包括DyNeRF [148]和NeuralRecon [149]等显著贡献。特别是，在连贯的3D重建研究前沿[149]，[150]，强调无缝生成新的场景块，利用已有场景结构的空间和语义连续性，成为其显著特点。值得注意的是，Sora [5]通过提供在统一视频框架内渲染单个角色多个视角的能力，并将物理世界模拟整合其中，脱颖而出。这些进展预示着无限3D场景重建和生成的新纪元，预计将在各个领域产生深远影响。在游戏领域，例如，这项技术允许实时生成3D环境，并实例化符合现实物理的对象，可能不再需要传统的游戏物理引擎。

# 5.3 增强型数字双胞胎

数字孪生（DT）是物理对象、系统或过程的虚拟复制品，旨在在数字平台上模拟真实实体。它们在各个行业中的模拟、分析和控制方面得到了广泛应用。其概念是，数字孪生接收来自其物理对应体的数据（通常通过传感器和其他数据收集方法实现实时传输），并可以预测物理孪生在各种条件下的行为或对环境变化的反应。数字孪生的关键特性在于能够准确地反映物理世界，使其能够像现实世界的对应物一样对外部信号或变化做出反应。这一能力使得操作优化、预测性维护和决策改善成为可能，因为数字孪生可以基于不同情景模拟结果，而不会对物理对象造成影响。Sora的世界模拟能力有潜力显著增强当前的数字孪生系统。数字孪生面临的主要挑战之一是确保实时数据的准确性，因为不稳定的网络连接可能导致关键数据片段的丢失。这种损失是至关重要的，可能削弱系统的有效性。目前的数据补全方法通常缺乏对对象物理属性的深入理解，主要依赖于数据驱动的方法。通过利用Sora在理解物理原理方面的优势，可能生成与基本真实世界现象更加一致且物理上连贯的数据。数字孪生的另一个关键元素是视觉系统的响应准确性，有效模拟和反映现实世界。目前的方法通常涉及用户通过编程触发事件，然后应用机器学习算法来预测并随后可视化结果。这个过程复杂，通常缺乏对物体物理特性的全面理解。实施Sora可能在这方面简化流程，使用户能够与系统进行统一的交互。用户可以直接与Sora创建的可视化界面互动，该界面能够进行实时预测，并提供准确且类似现实的视觉反馈，同时考虑到所涉及对象的物理属性。

# 5.4 建立人工智能应用的规范框架

随着 DALL·E、Midjourney 和 Sora 等大型生成模型的快速发展，这些模型的能力得到了显著提升。尽管这些进步可以提高工作效率并激发个人创造力，但对这些技术的滥用也引发了担忧，包括假新闻生成、隐私侵犯和伦理困境。目前，建立人工智能应用的规范框架变得必要且紧迫。这些框架应合法地回答以下问题：如何解释人工智能的决策。目前，大多数人工智能技术被视为黑箱。然而，可靠的人工智能的决策过程应是可解释的，这对于监督调整和信任增强至关重要。如何保护用户隐私。个人信息保护已成为社会关注的问题。随着对数据需求日益增长的人工智能的发展，应建立更详细和严格的法规。如何确保公平并避免歧视。人工智能系统应公平地服务于所有用户，不应加剧现有的社会不平等。为此，在算法设计和数据收集阶段，必须整合公平原则，并积极避免偏见和歧视。总的来说，规范框架将涵盖社会和技术两个层面，以确保人工智能应用的开发能惠及整个社会。

# 6 结论

基于Sora的分解，本调查提供了对当前T2V工作的全面回顾。具体而言，我们从生成模型的演变角度组织文献，包括GAN/VAE、自回归模型和扩散模型框架。此外，我们深入探讨并回顾了基于优秀视频应具备的三项关键特质的文献：延长时长、优越分辨率和无缝质量。此外，作为被声明为现实世界模拟器的Sora，我们展示了一个真实的全景，其中包括动态运动、复杂场景、多对象和合理布局。此外，视频生成中常用的数据集和指标根据其来源和应用领域进行了分类。最后，我们识别了一些T2V中剩余的挑战和问题，并提出了未来发展的潜在方向。
