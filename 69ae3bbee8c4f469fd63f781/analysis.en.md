# 2. Executive Summary

## 2.1. Background & Motivation
### Core Problem
The core problem addressed is the complexity and rapid evolution of **Text-to-Video (T2V)** generation. While Text-to-Image (T2I) models (like DALL·E, Midjourney) have matured, generating coherent, high-quality video remains significantly harder due to temporal dynamics, motion consistency, and physical realism.

### Importance and Gaps
The introduction of **Sora** by OpenAI marks a pivotal step toward Artificial General Intelligence (AGI) by simulating world dynamics. However, despite Sora's success, it faces unresolved obstacles. Prior to this work, two relevant surveys existed ([46] and [47]), but they were either too broad (covering editing and limited diffusion techniques) or lacked depth in the specific T2V domain relative to Sora's capabilities.

### Innovative Idea
This paper bridges the gap by offering an exhaustive review specifically framed around **"What We Can See" from Sora**. Instead of a generic history, it deconstructs Sora's architecture and capabilities to organize the entire T2V landscape into logical dimensions that highlight what modern models can and cannot do.

## 2.2. Main Contributions / Findings
1.  **Comprehensive Review:** It systematically tracks and summarizes the latest T2V literature, distilling core elements from Sora.
2.  **Foundational Clarity:** It elucidates concepts like generative models (GAN, VAE, Diffusion, Transformers) crucial for understanding the field.
3.  **Categorical Framework:** Literature is categorized into **Evolutionary Generators**, **Excellent Pursuit**, and **Realistic Panorama**.
4.  **Standardized Resources:** It provides an extensive survey of commonly used T2V datasets and evaluation metrics.
5.  **Critical Insight:** It illuminates current challenges (e.g., physics modeling, object permanence) and proposes future directions (e.g., Robot Learning, Digital Twins).

# 3. Prerequisite Knowledge & Related Work

## 3.1. Foundational Concepts
To understand this survey, a reader must grasp several fundamental machine learning architectures. These concepts are reviewed in Section 2 of the paper.

### Generative Adversarial Networks (GAN)
A GAN consists of two neural networks competing in a zero-sum game: a **Generator ($G$)** and a **Discriminator ($D$)**.
*   **Generator:** Creates synthetic data (e.g., video frames) intended to fool the discriminator.
*   **Discriminator:** Attempts to distinguish between real data (from the training set) and fake data (generated by $G$).
    The optimization objective is formulated as a minmax game:
$$
\operatorname* { m a x } _ { D } \underset { G } { \operatorname { m i n } } \mathbf { V } ( G , D )
$$
Where the value function $\mathbf{V}(D, G)$ is:
$$
\mathbb { E } _ { { x } \sim { p } _ { \mathrm { d a t a } } ( { x } ) } [ \log D ( { x } ) ] + \mathbb { E } _ { { z } \sim { p } _ { z } ( { z } ) } [ \log ( 1 - D ( G ( { z } ) ) ) ]
$$
Here, $x$ is real data sampled from $p_{\mathrm{data}}(x)$, and $z$ is noise sampled from $p_z(z)$ (usually Gaussian).

### Variational Autoencoders (VAE)
VAEs are deep generative models rooted in Bayesian inference. They consist of an **Encoder** (mapping input to a latent distribution) and a **Decoder** (reconstructing input from the latent variable).
The objective is to maximize the Evidence Lower Bound (ELBO):
$$
\begin{array} { r } { \mathcal { L } ( \boldsymbol { \theta } , \omega ; \boldsymbol { x } ) = \mathbb { E } _ { q _ { \omega } ( \mathbf { z } | \boldsymbol { x } ) } [ \log p _ { \boldsymbol { \theta } } ( \boldsymbol { x } | \mathbf { z } ) ] - \mathrm { KL } [ q _ { \omega } ( \mathbf { z } | \boldsymbol { x } ) \| p ( \mathbf { z } ) ] } \end{array}
$$
Where the first term is reconstruction loss and the second is Kullback-Leibler divergence regularization.

### Diffusion Models
Diffusion models generate data by reversing a noise-adding process.
1.  **Forward Process:** Gradually adds noise to data $x_0$ over steps $t=0$ to $T$, eventually resulting in Gaussian noise $x_T$.
    $$
    q ( x _ { t } | x _ { t - 1 } ) = \mathcal { N } ( x _ { t } ; \sqrt { 1 - \beta _ { t } } x _ { t - 1 } , \beta _ { t } \mathbf { I } )
    $$
2.  **Reverse Process:** A neural network learns to estimate the noise $\epsilon_\theta$ added at each step to reconstruct the original image.
    $$
    p _ { \theta } ( x _ { t - 1 } | x _ { t } ) = \mathcal { N } ( x _ { t - 1 } ; \mu _ { \theta } ( x _ { t } , t ) , \Sigma _ { \theta } ( x _ { t } , t ) )
    $$

### Autoregressive (AR) Models
These predict the next element in a sequence based on previous elements ($v_t = \sum \theta_i v_{t-i} + \epsilon_t$). In Deep Learning, Transformers leverage this to generate sequences token-by-token (e.g., predicting pixels or patches sequentially).

### Transformers
Transformers rely on **Self-Attention**, which allows the model to prioritize different parts of the input sequence.
$$
{ \mathrm { A t t e n t i o n } } ( Q , K , V ) = { \mathrm { s o f t m a x } } \left( { \frac { Q K ^ { T } } { \sqrt { d _ { k } } } } \right) V
$$
`Q, K, V` stand for Query, Key, and Value matrices derived from inputs. This mechanism enables handling long-range dependencies efficiently.

## 3.3. Technological Evolution
The field has evolved from early **GAN/VAE-based** attempts (Section 3.1.1) to **Diffusion-based** models (Section 3.1.2) which currently dominate due to higher fidelity. Recently, **Autoregressive Transformers** (Section 3.1.3) like Nuwa and Genie have emerged to handle long-context sequences. Sora itself represents a shift from the traditional U-Net architecture to a **Diffusion Transformer (DiT)**, scaling up parameters significantly to learn from internet-scale data.

1.  **Generators:** How models evolve algorithmically.
2.  **Quality Pursuits:** Extended duration, superior resolution, seamless quality.
3.  **Realism:** Dynamic motion, complex scenes, multiple objects, rational layout.
    This approach directly links theoretical methods to practical visual outcomes observable in Sora's demos.

# 4. Methodology

## 4.1. Principles
The core principle of this survey is **decomposition based on observation**. Rather than listing papers chronologically, the authors categorize literature based on the functional capabilities demonstrated by Sora. This requires understanding the underlying algorithms (Section 2) and then mapping them to three critical dimensions of video generation quality.

## 4.2. Core Methodology In-depth (Layer by Layer)
The "methodology" here refers to the classification system used to analyze the vast literature.

### 4.2.1. Evolutionary Generators
The authors classify models into three families based on their foundational architecture.
*   **GAN/VAE-based:** Early works like TGANs-C [60] combined 3D convolutions and multi-component loss functions for temporal coherence. Hybrid models combine VAE and GAN to capture static attributes and dynamic elements simultaneously.
*   **Diffusion-based:** This is the dominant paradigm. Models like **Video Diffusion Models (VDM)** [64] extend 2D image diffusion to 3D via **3D U-Net** [65].
    *   **Temporal Attention:** To ensure consistency, temporal layers (1D convolutions or attention) are added to the 2D UNet structure.
    *   **Latent Space:** Most modern models (LVDM [14], MagicVideo [66]) operate in a compressed latent space using a Video VAE to reduce computational cost.
    *   **Transformer Integration:** Sora shifts from U-Net to **DiT (Diffusion Transformer)** [6]. This involves transforming latent dimensions into non-overlapping tokens processed through transformer blocks.
*   **Autoregressive-based:** Models like **NuWA** [78] and **Phenaki** [13] compress video into discrete tokens and generate them sequentially using Transformers. This allows for handling variable-length videos and infinite synthesis (e.g., NUWA-Infinity [79]).

### 4.2.2. Excellent Pursuit (Quality Dimensions)
The survey analyzes models striving for specific quality metrics:
1.  **Extended Duration:** Long-term prediction suffers from error accumulation. Techniques include **retrospection mechanisms** (LTVR [11]) and hierarchical frameworks (LVDM [14]).
2.  **Superior Resolution:** High resolution requires significant resources. Methods like **Show-1** [28] combine pixel-based VDMs for low-res initialization with latent-based VDMs for upscaling. **STUNet** [29] uses Spatial SuperResolution (SSR) with Multi-Diffusion to smooth transitions.
3.  **Seamless Quality:** Addressing jitter and blurriness. **DAIN** [32] exploits depth information for occlusion handling during frame interpolation. **FLAVR** [35] learns motion properties directly to simplify training for high FPS.

### 4.2.3. Realistic Panorama (Physical Simulation)
To achieve "world simulation," four components must be mastered:
1.  **Dynamic Motion:** **AnimateDiff** [86] integrates pre-trained motion modules into T2I models. **MotionDiffuse** [75] uses Cross-Modality Linear Transformers for fine-grained human motion control.
2.  **Complex Scene:** **VideoDirectorGPT** [41] uses LLMs for planning scene descriptions. **FlowZero** [42] translates prompts into Dynamic Scene Syntax (DSS) for spatial layout guidance.
3.  **Multiple Objects:** To prevent attribute/object mixing, **Detector Guidance (DG)** [36] manipulates cross-attention maps. **UniVG** [39] uses Multi-condition Cross-Attention to manage multiple subjects.
4.  **Rational Layout:** Ensuring logical arrangement. **Craft** [44] predicts entity locations sequentially. **LVD** [45] generates Dynamic Scene Layouts (DSL) via LLMs to guide diffusion.

### 4.2.4. Datasets and Metrics (Technical Implementation Details)
The survey emphasizes that evaluation relies heavily on specific quantitative metrics.
*   **PSNR (Peak Signal-to-Noise Ratio):** Quantifies reconstruction quality per frame.
    $$
    \mathbf { P S N R } = 1 0 \cdot \log _ { 1 0 } ( \frac { \mathrm { M A X } _ { I _ { o } } ^ { 2 } } { \mathrm { M S E } } )
    $$
    Where $\mathrm{MSE} = \frac { 1 } { M N } \sum _ { i } \sum _ { j } [ I _ { o } ( i , j ) - I _ { g } ( i , j ) ] ^ { 2 }$.
*   **SSIM (Structural Similarity Index):** Measures perceptual similarity based on luminance, contrast, and structure.
    $$
    \mathbf { S S I M } = \frac { ( 2 \bar { I } _ { o } \bar { I } _ { g } + \delta _ { 1 } ) ( 2 \Sigma _ { I _ { o } I _ { g } } + \delta _ { 2 } ) } { ( \bar { I } _ { o } ^ { 2 } + \bar { I } _ { g } ^ { 2 } + \delta _ { 1 } ) ( \Sigma _ { I _ { o } } ^ { 2 } + \Sigma _ { I _ { g } } ^ { 2 } + \delta _ { 2 } ) }
    $$
*   **FVD (Fréchet Video Distance):** Evaluates video quality by combining means and covariance matrices extracted from I3D features.
    $$
    \mathbf { F V D } = | | \bar { \mathcal { V } } - \bar { \mathcal { V } } ^ { * } | | ^ { 2 } + \operatorname { T r } ( \Sigma _ { \mathcal { V } } + \Sigma _ { \mathcal { V } ^ { * } } - 2 ( \Sigma _ { \mathcal { V } } \Sigma _ { \mathcal { V } ^ { * } } ) ^ { 1 / 2 } )
    $$
    Where $\bar{\mathcal{V}}$ is the expectation of realistic videos and $\bar{\mathcal{V}}^*$ is the generated videos.

## 5.2. Evaluation Metrics
The survey categorizes metrics into **image-level** and **video-level**.

### 5.2.1. Conceptual Definition
*   **Image-level:** Evaluate generated video frames individually (e.g., clarity, similarity to reference).
*   **Video-level:** Evaluate comprehensive video quality (temporal coherence, motion fluidity).

### 5.2.2. Mathematical Formulas & Symbols
*   **Inception Score (IS):** Measures quality and diversity using a pre-trained Inception network.
    $$
    \mathbf { I S } = \exp ( \mathbb { E } _ { I _ { g } } [ \mathrm { KL } ( p ( y | I _ { g } ) | | p ( y ) ] ) )
    $$
    Where $p(y|I_g)$ is the conditional label distribution and `p(y)` is the marginal distribution.
*   **Fréchet Inception Distance (FID):** Considers similarity between generated and original images more comprehensively than IS.
    $$
    { \bf F I D } = | | \bar { I } _ { o } - \bar { I } _ { g } | | ^ { 2 } + \mathrm { T r } ( \Sigma _ { I _ { g } } + \Sigma _ { I _ { r } } - 2 ( \Sigma _ { I _ { g } } \Sigma _ { I _ { r } } ) ^ { 1 / 2 } ) .
    $$
    Here $\mathrm{Tr}$ is the matrix trace, and $\bar{I}$ denotes mean vectors.
*   **CLIP Score:** Measures alignment between image and sentence using cosine similarity of embeddings $\mathcal{E}_I$ and $\mathcal{E}_S$.
    $$
    \mathbf { C L I P } _ { s c o r e } = \mathbb { E } [ \operatorname* { m a x } ( \cos ( \mathcal { E } _ { I } , \mathcal { E } _ { S } ) , 0 ) ] .
    $$
*   **Frame Consistency Score (FCS):** Measures consistency across frames using CLIP image embeddings.

# 6. Results & Analysis

## 6.1. Core Results Analysis
While this is a survey, the "results" refer to the comparative analysis of the state of the art drawn from the literature.
*   **Sora's Performance:** Sora demonstrates superior capabilities in rendering complex scenes with intricate details, surpassing prior studies focused on complex scenes [24], [40]. It produces minute-long videos of high quality, a feat not previously accomplished by existing T2V studies.
*   **Architecture Shift:** The most significant finding is the industry shift from **U-Net** to **DiT (Diffusion Transformer)**. This allows Sora to scale efficiently with internet-scale data.
*   **Gap Analysis:** Despite improvements, Sora still encounters obstacles:
    1.  **Coherent Motion:** Struggles with ensuring consistent motion among multiple objects.
    2.  **Physics:** Sometimes fails to simulate accurate physical interactions (e.g., objects passing through hoops without explosion).
    3.  **Object Permanence:** Intermittent appearances/disappearances of objects occur (e.g., wolf pups appearing/disappearing mid-scene).

# 7. Conclusion & Reflections

## 7.1. Conclusion Summary
This survey provides a comprehensive review of Text-to-Video generation, structured around the capabilities of OpenAI's Sora. By decomposing the technology into evolutionary generators, excellent pursuits (quality), and realistic panoramas (physics/scenes), it offers a nuanced map of the field. It concludes that while Sora represents a milestone in world simulation, significant challenges regarding physics, object permanence, and privacy remain unsolved.

## 7.2. Limitations & Future Work
The authors identify several critical challenges and future directions:
*   **Data Privacy:** Leveraging private, non-sensitive data (via Federated Learning) to improve generalizability without violating privacy.
*   **Multi-Agent Co-creation:** Developing systems where LLM agents collaborate (director, actor roles) to generate cohesive videos.
*   **Simultaneous Multi-shot Generation:** Improving consistency across multiple shots in a single sample for robotics or autonomous driving simulations.
*   **Robot Learning:** Using T2V for Learning from Demonstration (LfD) by integrating with 3D reconstruction (NeRF, 3DGS).
*   **Digital Twins:** Creating virtual replicas of physical systems using Sora's physical understanding.
*   **Normative Frameworks:** Establishing regulations for AI applications to prevent misuse (fake news, bias).

## 7.3. Personal Insights & Critique
*   **Strengths:** The categorization framework (Evolutionary, Excellent, Realistic) is highly intuitive and effectively bridges the gap between abstract algorithmic progress and tangible video quality. The inclusion of detailed mathematical formulas for metrics provides a solid reference for practitioners.
*   **Critique:** As a survey of a rapidly evolving field dominated by a closed-source model (Sora), some aspects rely heavily on public demonstrations rather than official whitepaper disclosures. For instance, the exact architecture of Sora is inferred ("Disassembly") rather than fully documented. This introduces some speculation in the architectural claims, although well-grounded in the DiT lineage.
*   **Transferability:** The discussion on **Digital Twins** and **Robot Learning** is particularly inspiring. It suggests T2V is not just for entertainment but for simulating physical laws for industrial safety and automation. The emphasis on "Physics Understanding" as a metric for video generation quality sets a new standard for future evaluations beyond FID.
