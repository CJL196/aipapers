摘要——在多样化机器人数据集上预训练的大型策略具有改变机器人学习的潜力：这种通用机器人策略可以在仅有少量领域内数据的情况下进行微调，而不必从头开始训练新策略，并且能够广泛泛化。然而，要在各种机器人学习场景、环境和任务中广泛适用，这些策略需要处理多样的传感器和动作空间，适应各种常用的机器人平台，并能够高效地微调到新领域。在这项工作中，我们旨在为开发开源、广泛适用的通用机器手操作策略奠定基础。作为第一步，我们介绍了Octo，一种基于大型变换器的策略，基于来自开放X-体现数据集的800,000条轨迹进行训练，这是迄今为止最大的机器人操控数据集。它可以通过语言指令或目标图像进行指导，并且能够在标准消费级GPU上在数小时内有效微调到具有新感官输入和动作空间的机器人设置。在对9个机器人平台的实验中，我们展示了Octo作为一种多功能策略初始化，可以有效微调到新的观察和动作空间。我们还对Octo模型的设计决策进行了详细的消融实验，包括架构和训练数据，以指导未来在构建通用机器人模型方面的研究。

# I. 引言

机器学习的常见方法是在针对特定机器人和任务收集的数据集上训练策略。以这种方式从头开始学习需要为每个任务进行大量的数据收集努力，并且所获得的策略通常只展现出狭窄的泛化能力。从原则上讲，来自其他机器人和任务的收集经验提供了一种可能的解决方案，使模型接触到多样化的机器人控制问题，从而可能改善下游任务的泛化和性能。然而，即使通用模型在自然语言和计算机视觉中变得无处不在，构建类似的“通用机器人模型”以控制多个机器人执行多种任务仍然十分具有挑战性。在机器人领域训练统一控制策略面临独特的挑战，需要处理不同的机器人体现、传感器设置、动作空间、任务规范、环境和计算预算。

朝着这个方向，几项研究提出了机器人基础模型，这些模型直接将机器人观察映射到动作，并提供对新领域和新机器人的零-shot或少-shot泛化。我们广泛地将这些模型称为“通用机器人策略”（GRPs），强调它们在不同任务、环境和机器人系统中执行低级视觉运动控制的能力。例如，GNM模型在不同的机器人导航场景中进行泛化，RoboCat模型处理不同的机器人体现以满足目标条件任务，而RT-X模型在五个机器人体现中执行语言条件的操作。尽管这些模型在朝着真正的“通用机器人模型”迈出了重要一步，但在多个重要方面仍存在局限性：它们通常将下游用户限制在预定义且常常限制性较强的输入观察集，例如单一摄像头流；它们缺乏对新领域有效微调的支持；更重要的是，这些模型中最大的并未向广大公众开放。

我们设计了一个系统，用于预训练更适合下游机器人应用中接口多样性的通用机器人策略。我们模型的核心是一个变压器架构，它将任意输入令牌（由观察和任务创建）映射到输出令牌（然后解码为动作），可以在多样化的机器人和任务数据集上进行训练。在没有额外训练的情况下，该策略可以接受不同的摄像头配置（例如，工作空间或腕部摄像头），能够控制不同的机器人，并可以通过语言命令或目标图像进行指导——这只需简单地改变输入模型的令牌。最重要的是，该模型可以通过添加适当的适配器并使用小型目标领域数据集和可访问的计算预算进行微调，从而适应具有新传感器输入、动作空间或形态的新机器人设置。

我们的主要贡献是Octo，这是一种基于变压器的策略，经过在迄今为止最大的机器人操作数据集上进行预训练：来自Open X-Embodiment数据集的$8 0 0 \mathrm { k }$机器人演示。Octo是第一个可以有效微调到新的观测和动作空间的GRP，也是第一个完全开源的通用机器人操作策略，包括训练流程、模型检查点和数据。最后，尽管组成Octo的各个组件——变压器骨干、对语言和目标图像规格的支持以及用于建模表现性交互分布的扩散头——在之前的工作中已经讨论过，但将这些组件特殊组合成一个强大的通用机器人策略是独特而新颖的。

我们通过在4个机构的9个机器人上进行广泛实验，展示了我们的联合系统在开箱即用的多机器人控制中，对于单臂和双臂操作任务达到了领先的性能，并且Octo可以作为有效的初始化，用于微调到具有新观察和动作空间的未见设置。在此过程中，我们仔细研究了在预训练GRP时不同设计决策的影响；我们评估了数据分布、模型架构和策略制定的选择如何影响预训练GRP的质量。我们的评估突出了规模和灵活性的实用性：我们最好的模型是那些在最广泛的数据混合上训练的，具有最少的限制性归纳偏见，以及具有能够适应预训练数据中行为多样性的策略目标。

随本论文发布，我们提供所有所需资源，以训练、使用、重现和微调Octo模型。我们提供了预训练的Octo模型检查点，包含2700万和9300万参数，这些模型开箱即用，支持多个RGB摄像头输入，以及语言和目标图像任务规范。我们还提供了在新领域微调这些模型的脚本，以及我们的完整预训练流程，包括优化的数据加载器、多模态输入的变换器实现和用于监控训练进度的工具。

# II. 相关工作

许多研究通过使用从机器人收集的大量轨迹数据集来训练策略，从早期使用自主数据收集进行政策培训的努力[71, 48, 41, 19, 27, 30]，到最近探索现代基于变压器的策略与大型演示数据集结合的努力[10, 40, 98, 28, 83, 86]。这些研究主要集中于单一的体现，而Octo则在跨多个体现的机器人数据集上训练策略，增加了训练数据集的有效大小，并允许对各种机器人设置进行微调。

最近，研究论文着重于扩大机器人策略的泛化能力。多项工作利用多样的非机器人数据或预训练的视觉-语言基础模型来提升策略在新场景和任务中的泛化能力 [86, 103, 96, 16, 38, 11, 84, 36, 4, 37, 7, 3, 46, 15, 23]。与Octo更相关的是，近期的一些工作训练跨多个机器人实现的数据的机器人策略：GNM模型 [81, 80] 在机器人导航配置中进行泛化，而RoboCat [9] 和RT-X [67] 控制多个单臂操纵机器人。虽然这些模型在策略学习方面取得了令人印象深刻的成果，但一个关键问题是它们缺乏灵活性：它们通常要求用户坚持使用预训练期间的传感器输入和动作空间，并且不支持适应新的观察和动作空间。此外，最大的模型并未公开访问。Octo在多个方面与这些工作不同：它在更大和更多样的机器人数据混合上进行训练，支持通过高效的微调适应新的机器人配置来扩展更广泛的下游应用，并且是完全开源和可重复的。

Octo的设计灵感来自于几个最近在机器人模仿学习和可扩展变换器训练方面的进展，包括使用去噪扩散目标[34]进行动作解码[17, 31, 85]、“动作块”的预测，即未来动作的序列[98, 17, 28]，以及受可扩展视觉变换器训练文献启发的模型布局和学习率调度[22, 97]。我们的工作是首次在学习跨体泛化策略的背景下利用这些方法，我们发现它们能够带来显著的性能提升。在我们的评估中，我们呈现了各种消融实验，以评估这些组件的重要性，并在附录E中列出了我们发现的（不）重要的更全面列表；我们希望我们的研究结果对未来的泛化策略学习研究有所帮助。

训练通用机器人策略的关键组成部分是机器人训练数据。与可以从网络抓取的视觉和语言数据相比，大规模获取机器人数据具有挑战性，通常需要在硬件和人力上进行重大投资。目前有多个大型机器人导航和自动驾驶数据集[29, 95, 13, 87, 80, 43, 89]。近年来，也有多个努力在构建规模和多样性日益增长的机器人操作数据集，这些数据集通过脚本化和自主策略 [19, 41, 42, 12, 71, 30] 或人类遥控 [59, 60, 25, 90, 39, 10, 26, 6, 77, 63, 79] 收集而成。Octo是基于Open X-Embodiment数据集[67]进行训练的，这是一个汇集了许多上述机器人数据集的最新努力。Open-X数据集包含约150万条机器人试验记录，其中我们为Octo训练整理了80万条。我们注意到，RT-X模型[67]使用了一个更有限的35万条记录子集，因此据我们所知，Octo是迄今为止训练在最大机器人操作演示数据集上的模型。

# III. Octo模型

在本节中，我们描述了Octo模型，我们的开源通用机器人策略，可以通过微调适应新机器人和任务——包括新的传感器输入和动作空间。我们讨论了关键设计决策、训练目标、训练数据集和基础设施。Octo模型的设计强调灵活性和可扩展性：它支持多种常用机器人、传感器配置和动作，同时提供通用和可扩展的配方，可以在大量数据上进行训练。它还支持自然语言指令、目标图像、观察历史和通过扩散解码进行多模态、分块的动作预测。此外，我们专门设计Octo以便高效地微调到新的机器人设置，包括具有不同动作空间和不同摄像头与自身感知信息组合的机器人。这个设计旨在使Octo成为一个灵活且广泛适用的通用机器人策略，可用于多种下游机器人应用和研究项目。

# A. 架构

Octo的核心是一个基于变换器的策略 $\pi$。它由三个关键部分组成：输入标记器将语言指令 $\ell$、目标 $g$ 和观察序列 $o_{1}, \ldots , o_{H}$ 转换为标记 $[ \mathcal{T}_{l}, \mathcal{T}_{g}, \mathcal{T}_{o} ]$（图2，左）；一个变换器骨干处理标记并产生嵌入 $e_{l}, e_{g}, e_{o} = T( \mathcal{T}_{l}, \mathcal{T}_{g}, \mathcal{T}_{o} )$（图2，顶部）；以及产生期望输出的读出头 $R(e)$，即动作 $a$。

任务和观察标记器：我们将任务定义（例如，语言指令 $\ell$ 和目标图像 $g$ 以及观察 $o$（例如，手腕和第三人称摄像头流）转换为一种通用的“标记化”格式，使用特定于模态的标记器（见图2，左侧）：

• 语言输入被标记化，然后通过一个预训练的变换器，生成一系列语言嵌入标记。我们使用 t5-base（111M）模型 [74]。   
图像观测和目标通过一个浅层卷积堆栈，然后分割成一系列扁平化的补丁 [22]。

我们通过将可学习的位置嵌入 $p$ 添加到任务和观察令牌中，来组装变压器的输入序列，然后按顺序排列它们 $\left[ \mathcal { T } _ { T } , \mathcal { T } _ { o , 1 } , \mathcal { T } _ { o , 2 } , \ldots \right]$。

Transformer骨干与读取头：一旦输入被转换为统一的令牌序列，它们就会被一个变压器处理（见图2，顶部）。这与以前的工作相似，这些工作在观察和行动的序列上训练基于变压器的策略[92, 73]。Octo变压器的注意力模式是块状掩蔽的：观察令牌只能因果地关注来自相同或更早时间步的令牌$\mathcal { T } _ { o , 0 : t }$以及任务令牌$\mathcal { T } _ { T }$（绿色）。对应于不存在的观察的令牌被完全掩蔽（例如，没有语言指令的数据集）。这种模块化设计使我们能够在微调期间添加和删除观察或任务（见下文）。除了这些输入令牌块，我们还插入了学习到的读取令牌$\mathcal { T } _ { R , t }$（紫色）。在序列中，位于$\mathcal { T } _ { R , t }$的读取令牌关注其之前的观察和任务令牌，但不被任何观察或任务令牌关注——因此，它们只能被动地读取和处理内部嵌入，而不影响它们。读取令牌的作用类似于BERT中的[CLS]令牌，作为目前为止观察序列的紧凑向量嵌入。对读取令牌的嵌入应用一个轻量级的“行动头”，该头实现扩散过程。这个行动头预测一“段”连续的多个行动，类似于之前的工作[98, 17]。

我们的设计允许我们在下游微调过程中灵活地向模型添加新的任务和观察输入或动作输出头。在添加新的任务、观察或损失函数时，我们可以完全保留变压器的预训练权重，仅根据规范的变化添加新的位置嵌入、新的轻量级编码器或新头的参数（见图2，底部）。这与之前的架构[10, 81]形成对比，后者在添加或移除图像输入或更改任务规范时需要重新初始化或重新训练预训练模型的大部分组件。

这种灵活性对于使Octo成为真正的“通用”模型至关重要：由于我们无法在预训练期间覆盖所有可能的机器人传感器和动作配置，因此在微调过程中能够适应Octo的输入和输出使其成为机器人社区的多功能工具。之前的模型设计使用标准的变换器骨干或将视觉编码器与MLP输出头结合，锁定了模型预期的输入类型和顺序。相比之下，更改Octo的观察或任务并不需要重新初始化大多数模型。

# B. 训练数据

我们在来自开放X体现数据集[67]的25个数据集的混合数据上训练Octo，这是一组多样化的机器人学习数据集。我们的训练混合数据包括来自多个机器人体现和场景的各种任务的演示数据。这些数据集在机器人类型、传感器（例如，包括或不包括手腕摄像头）和标签（例如，包括或不包括语言指令）等方面都是异构的。有关详细混合情况，请参见图3和附录C。为了创建我们的训练混合数据$D$，我们通过首先去除所有不包含图像流的开放X数据集，以及那些不使用增量末端执行器控制的数据集来整理数据。我们还移除了过于重复、图像分辨率过低或由过于小众的任务组成的数据集。对于剩余的数据集，我们根据任务和环境将它们大致分类为“更具多样性”和“较少多样性”数据集，并在训练过程中将更具多样性的数据集的权重加倍。我们还降低了一些包含许多重复剧集的数据集的权重，以避免在混合数据中占主导地位。最后，对于任何缺失的摄像头通道，我们使用零填充，并在数据集之间对齐夹持器的动作空间，使得夹持器命令$+1$表示“夹持器打开”，0表示“夹持器关闭”。尽管我们发现最终的训练混合数据效果良好，未来的工作应对数据混合质量进行更全面的分析，以预训练通用机器人策略。

# C. 训练目标

我们使用条件扩散解码头来预测连续的多模态动作分布 [34, 17]。重要的是，每个动作预测仅进行一次变压器主干的前向传播，之后的多步去噪过程完全在小型扩散头内进行。我们发现这种策略参数化在零-shot 和微调评估中优于使用均方误差（MSE）动作头或离散动作分布 [10] 训练的策略。为了生成一个动作，我们对一个高斯噪声向量 $x ^ { K } \sim \mathcal { N } ( 0 , I )$ 进行采样，并应用 $K$ 步去噪，使用一个学习的去噪网络 $\epsilon _ { \theta } ( x ^ { k } , e , k )$ ，该网络以先前去噪步骤的输出 $x ^ { k }$、步骤索引 $k$ 和变压器动作读取的输出嵌入 $e$ 为条件。

$$
x ^ { k - 1 } = \alpha ( x ^ { k } - \gamma \epsilon _ { \theta } ( x ^ { k } , e , k ) + \mathcal { N } \big ( 0 , \sigma ^ { 2 } I \big ) ) .
$$

超参数 $\alpha, ~ \gamma$ 和 $\sigma$ 对应于噪声调度：我们使用自[66]以来的标准余弦调度。我们首先使用在[34]中首次提出的标准DDPM目标训练扩散头，在数据集动作上添加高斯噪声，并训练去噪网络 $\epsilon _ { \theta } ( x ^ { k } , e , k )$ 以重构原始动作。有关扩散策略训练的详细说明，请参见Chi等人[17]。我们在附录D中列出了所有超参数。

在微调过程中，我们使用相同的扩散训练目标并更新完整模型，这种方法优于固定预训练参数的子集。在所有的微调实验中，我们采用相同的方案：给定一个包含约100条轨迹的小型目标领域数据集，我们微调 $5 0 \mathrm { k }$ 步，使用余弦衰减学习率和线性预热。

# D. 训练细节

我们训练了两种变体的模型：Octo-Small，其变换器骨干网络与ViT-S的大小相当，以及Octo-Base，其变换器骨干网络与ViT-B的大小相当[22]。

我们使用AdamW优化器[51]，采用逆平方根衰减学习率计划[97]，权重衰减为0.1，梯度裁剪为1.0。ViT-B模型在一个TPU v4-128集群上训练了300k步，批处理大小为2048，共耗时14小时。在一台拥有24GB显存的NVIDIA A5000 GPU上对同一模型进行微调大约需要5小时，并且可以通过多GPU训练加速。

我们使用2帧观察历史进行训练；在我们的初步实验中，我们发现超出第一帧的额外帧所带来的收益显著递减。我们使用事后目标重新标记[2]，该方法从轨迹中的未来状态均匀选择一个状态作为目标图像，类似于之前的工作[54, 90, 81, 77, 63]。我们在训练过程中应用常见的图像数据增强，并随机将每个训练示例中的语言指令或目标图像归零，使Octo能够基于语言指令或目标图像进行条件训练。对于没有语言注释的数据集，我们始终使用目标图像条件。这使我们的模型能够主要从自监督的视觉观察中学习控制，并减少对语言注释的依赖，类似于之前关于多上下文模仿学习的工作[54, 62, 61, 63]。有关超参数选择的更多细节，请参见附录D。

# C. 通用型机器人策略训练的设计决策

我们已经证明了Octo作为零样本多机器人控制器和策略微调初始化的有效性。接下来，我们分析不同设计决策对Octo策略性能的影响。具体来说，我们关注以下几个方面：（1）模型架构，（2）训练数据，（3）训练目标，以及（4）模型规模。除非另有说明，否则我们所有的消融实验都在OctoSmall模型上进行，因为我们的计算预算有限。

模型架构：以往基于变压器的策略设计通常使用大型 ResNet 风格的编码器对输入图像进行编码，并将生成的图像特征与相对较小的变压器融合。相反，我们选择了“变压器优先”的架构，该架构使用非常浅的 CNN 补丁编码器，并将大部分参数和 FLOPS 集中在变压器主干中，类似于经典的视觉变压器架构。在表 II 中，我们显示了这种可扩展架构在全量 Open XEmbodiment 数据混合训练时显著提高了性能。重要的是，我们发现基于 ResNet 的架构在小型数据集上的表现优于 ViT，例如，在我们的“从头开始”的比较中，强调了大型变压器策略特别适合在多样化数据集上进行可扩展训练。

训练数据：Octo是迄今为止在最具多样性的跨体态机器人数据集上训练的，这是一组25个数据集的混合，我们从Open X-Embodiment数据集中手动整理而来 [67]（见第三节B）。我们通过与在用于训练RT-X模型的较小混合的11个数据集上训练的Octo模型进行比较，消融了这种训练混合的影响 [67]，以及仅在目标机器人领域的数据上训练的基线。在表II中，我们显示了随着训练数据集数量的增加，Octo的性能有所提高。这表明，将数据混合扩展到更多的数据集可能进一步提高策略性能。我们将把这留待未来的工作，连同对数据整理最佳实践的更深入研究。

# V. 讨论与未来工作

我们推出了Octo，一个基于大规模转换器的策略模型，预先在迄今为止最大的机器人操作数据集上进行训练，涵盖$800,000$条机器人轨迹。我们展示了Octo可以开箱即用地解决各种任务，并展示了Octo的组合设计如何使得对新输入和动作空间的微调成为可能，使Octo成为广泛机器人控制问题的多功能初始化。除了模型本身，我们还发布了完整的训练和微调代码，以及一些工具，方便在大型机器人数据集上进行训练。

虽然Octo在零-shot和微调评估中表现强劲，但我们发现当前模型仍存在多个不足之处，我们在很大程度上归因于训练数据的特征。首先，我们发现当前的Octo模型在处理腕部摄像头信息时表现不佳。通常，当仅使用第三人称摄像头而不组合第三人称和腕部摄像头时，微调结果更强。此外，我们注意到语言条件策略性能和目标条件策略性能之间存在很大差异。在这两种情况下，训练数据中缺乏相应模态是可能原因：只有27%的数据包含腕部摄像头信息，只有56%的预训练数据包含语言注释。

扩展用于训练Octo的数据是一个自然的改进方向。由于Open X-Embodiment数据集由最佳机器人演示构成，当前模型通过模仿进行训练；未来的工作可能会考虑从次优或在线互动数据中学习，这需要替代目标。此外，虽然我们仅在单臂和双臂操纵器上训练和评估Octo；扩展到执行导航或移动操作的更广泛机器人将是一个很有机会的方向。

Octo代表了朝着建立可即插即用的通用机器人策略迈出的一个步骤，能够在多样化的机器人配置上工作，但仍需改进模型，包括更好的语言条件、改进对手腕摄像头的支持，以及纳入超出最佳演示的数据。我们希望Octo为研究人员和从业者提供一个简单的启动平台，以访问更大的机器人数据集，并利用预训练的机器人模型高效学习新任务和广泛的泛化能力。
